# Авто-Помощник

Плагин [Astra](https://github.com/mihailinl/astra), который проверяет почту,
собирает дайджест важных писем и помогает создавать задачи, напоминания и
записи в календаре. Использует модель, настроенную в Astra; отдельный ключ
для ИИ не нужен.

❗❗❗ Важно: Для использования всех функций плагина, необходимо скачать Source code (zip), распаковать, далее в Разработке Загрузить плагин через Обзор

## Возможности

- Яндекс, Gmail, Mail.ru и другие почтовые сервисы с IMAP.
- Проверка по расписанию и вручную. Письма не помечаются прочитанными.
- Отбор по белому списку, правилам или с помощью модели Astra.
- Дайджест с кратким содержанием письма, задачами и сроками.
- Создание задач вручную или автоматически для важных писем.
- Сроки в календаре, напоминаниях или обоих списках.
- Голосовой ответ Astra и событие «Важное письмо найдено» для автоматизаций.
- Интерфейс с поддержкой темы Astra.

## Установка

Установите плагин из каталога Astra, когда он станет доступен там.
[Релизы и исходники](https://github.com/Voltur792/auto-assistant/releases).

При установке из локального `.astraplugin` Astra может отказать в доступе
к своему чату: тогда отбор работает по правилам, без модели и создания задач.
Для локального использования загрузите папку проекта через режим разработки
Astra и разрешите доступ к чату.

## Настройка

1. Откройте **Помощник → Почта → Добавить ящик**.
2. Укажите адрес и **пароль приложения** для IMAP, а не основной пароль.
3. Проверьте подключение и сохраните настройки.
4. Выберите режим отбора, интервал и способ записи сроков.
5. При необходимости включите автоматическое создание задач и озвучку.

В Яндексе нужно разрешить IMAP и создать пароль приложения типа «Почта».
В Gmail пароль приложения доступен при включённой двухэтапной проверке.
В Mail.ru используются пароли для внешних приложений.

Белый список — адреса, имена или их части, по одному в строке.
Пустой список разрешает всех отправителей.

При первом подключении устанавливается точка отсчёта: старые письма не
разбираются автоматически. Нажмите **Последние письма**, чтобы разобрать
последние непрочитанные письма. **Очистить** очищает дайджест.

## Задачи и сроки

Нажмите **Создать задачи через Астра** в дайджесте либо включите автоматический
режим. Успешно обработанные письма повторно не передаются. Результат виден
над дайджестом; при неподтверждённом создании письмо остаётся доступным для
повторной попытки.

Создание зависит от модели и доступных ей инструментов Astra. Проверка
результата использует списки задач, напоминаний и календаря. Если один запрос
выполнен частично, перед повтором проверьте уже созданные задачи: возможны
дубликаты. В Linux проверка по файлам Astra пока недоступна, поэтому результат
может остаться неподтверждённым.

Для уведомлений можно связать событие **Важное письмо найдено** с действием
в редакторе автоматизаций Astra.

## Разрешения и данные

Плагин запрашивает доступ к чату Astra для разбора писем и создания задач,
к событиям автоматизаций и к обновлению своей вкладки.

Текст писем передаётся модели, выбранной в Astra — локальной или облачной.
Почта только читается; плагин не отправляет и не удаляет письма.
Настройки и пароли приложений хранятся вне папки плагина и сохраняются после
переустановки. В Windows это `%APPDATA%\auto-assistant`, в Linux —
`$XDG_DATA_HOME/auto-assistant` или `~/.local/share/auto-assistant`.
