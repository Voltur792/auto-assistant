Почтовые ящики

Пароль приложения — не пароль от почты:
  1. Яндекс: id.yandex.ru → Безопасность → Пароли приложений → «Почта (IMAP)». Настроить → Почта → «Портал IMAP-клиентов» — включить.
  2. Gmail: аккаунт → Безопасность → 2-Step Verification (вкл) → App passwords → создать для Mail.
  3. Белый список — подстроки адреса или имени отправителя, по одному в строке. Пустой = проходить всем.
Пароли хранятся локально в %APPDATA%\auto-assistant — переживают переустановку плагина.
